# Scope

This repo is the set of skills I use myself. Feedback and ideas are welcome, and each one is judged against the bar below rather than against how large the change is.

## The bar

1. **Observed failure.** The report describes something that went wrong in a real session: what was asked, what the skill did, what was expected instead. A hypothetical improvement ("it would be better if ...") does not clear this bar on its own.
2. **Fits the philosophy.** Small, self-contained, harness-agnostic. A config option, a branch for one specific tool, or a tweak that only suits one person's workflow belongs in your own `AGENTS.md`, or in a fork. The skills are plain files; forking them is cheap and expected.

## New skills

I add a skill when I catch myself repeating the same workflow and the repeat has a clear, checkable finish line. Pull requests that add a whole new skill are usually closed with a pointer to fork instead, unless the workflow is one I already run.

## Open issues

An issue that cannot be judged against the bar gets one round of questions. Without a reply, it is closed.
