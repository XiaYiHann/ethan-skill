# Research

Skills for literature-facing work: reading papers, judging manuscripts, and keeping the evidence straight.

## Model-invoked

Model- or user-reachable: the description carries the trigger phrasing.

- **[rank-my-paper](./rank-my-paper/SKILL.md)**: Compare a finished manuscript against up to seven officially accepted same-domain peers, reviewed independently under a shared rubric, and return an evidence-bound ranking with revision priorities.
- **[darpa](./darpa/SKILL.md)**: Heilmeier Catechism review of the current work: eight hard questions on value, risk, cost, and milestones, with falsifiable exams. Written in Chinese.
